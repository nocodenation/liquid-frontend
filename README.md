# Liquid.MX Frontend

Frontend applications for the Liquid.MX platform.

## Structure

### orchids-projects/

Projects built with the Orchids framework - a Next.js-based rapid application development framework.

- **quality-event-system/** - Quality event tracking and management system

## Development

Each project has its own development setup. Navigate to the specific project directory for detailed instructions.

## Architecture

Frontend applications in this repository are designed to integrate with:
- **liquid-playground** - NiFi-based backend processing environment
- **liquid-library** - Shared NiFi components and extensions
- **liquid-rules** - Development guidelines and best practices
